# ArXiv preprint — figures

This folder holds the figures produced for the project's arXiv preprint.
They are **frozen historical snapshots**: the exact images generated by a
past state of the codebase (from before the `VLsim` → `PyOMES` rename in
some cases — see the note on `aqueous_ph_parity_plot.png` below), not
outputs that the current code is guaranteed to reproduce.

## Why these are kept as static files, not just regenerated from the demos

The demo notebooks under `demos/usecases/` are committed with their
output cells cleared, and `demos/**/figures/` (where re-running a
notebook saves its plots) is git-ignored. That means re-running a
notebook today reflects the *current* behaviour of PyOMES, which has
already changed since these figures were made — confirmed directly by
`aqueous_ph_parity_plot.png`'s own title, which still reads "VLsim vs.
PHREEQC" even though its axis label already says "PyOMES pH": a
mid-rename snapshot that today's equivalent notebook cell no longer
produces in that form (different color scheme, different panel layout).
So the notebooks document *how to generate this kind of figure*, not
*what was actually published* — these files are the only surviving
record of the latter.

## If you need to regenerate a similar figure

Use the notebook listed above as a starting point, but expect the exact
numbers, styling, and in some cases the underlying model behaviour to
have moved on since these were made. Pin to the specific PyOMES release
that was current when the preprint was submitted if exact reproduction
matters.
